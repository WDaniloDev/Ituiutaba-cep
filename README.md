# Consulta de CEPs Canônica — Ituiutaba / MG

Aplicação web desenvolvida como atividade prática da disciplina do curso de **Sistemas de Informação** da **Universidade do Estado de Minas Gerais (UEMG)**.

## Tecnologias Utilizadas
* **HTML5 Semântico**
* **CSS3 Puro** (Custom Properties, Flexbox & Grid)
* **JavaScript Vanilla** (Fetch API, Manipulação de DOM reativa)

## Funcionalidades
* Busca reativa com autocomplete inteligente (acionado a partir de 3 caracteres digitados).
* Exibição detalhada de logradouros, bairros e destaque visual dinâmico para o CEP.
* Modais informativos institucionais (Sobre, Nota de Transparência de IA, Termos de Uso e Privacidade).
